# 阶跃星辰

> 数据来源：腾讯新闻（2026-06-09、2026-05-08）、今日头条（2026-04 股改报道，援引天眼查/《财经》）、中国经济新闻网（2026-05）、网易新闻（2026-07）。检索日期：2026-07-27。所有数字均有出处；营收数据为第三方/媒体口径，公司未官方确认处已标注。

## 技术路线

「多模态卷王」路线：已发布 38 款基座模型，其中 31 款为多模态模型（网易 2026-07）。Step 3 系列采用 MoE 架构，总参数 321B、激活约 38B，在视觉语言推理、语音生成、视频理解方向取得开源成绩。2026-06-04 Step 3.7 Flash 拿下 Artificial Analysis 多个第一，被官方定义为「Agent 生产级模型」（腾讯新闻 2026-06-09）。2026-04-02 上线 Step 3.5 Flash 2603，面向高频编程与 Agent 工作流，新增低推理模式可将 Token 消耗降低 14%-56%。最新基座模型全栈开源，登上 OpenClaw 调用量月榜第一（腾讯新闻 2026-05-08）。强调推理效率与端侧部署：硬件感知设计、国产芯片适配、小模型优化。核心团队：CEO 姜大昕（前微软全球副总裁）、首席科学家张祥雨（ResNet 作者之一）。风险信号：OpenRouter 最新一周调用量 Top10 无阶跃模型，Step 3.5 Flash 排第 16 位、调用量 515B Tokens 且降幅 27%（中国经济新闻网 2026-05）。

## 产品定位

差异化锚定「AI+终端」：模型嵌入手机与汽车终端而非主打 Chatbot App。与 OPPO、荣耀、中兴等合作覆盖国内约 60% 头部手机品牌，累计装机量超 4200 万台，日均服务近 2000 万人次（多家媒体交叉印证）。汽车端与千里科技、吉利合作的智能座舱已搭载量产车型（银河 M9 等）。C 端产品偏弱：角色扮演产品「冒泡鸭」已停投并入 App「阶跃AI」，后者未进入 AI 原生 App 月活前十（QuestMobile 2026-03，腾讯新闻转引）。业内定位：「大模型六小虎第一梯队中游偏上，标签是多模态+重工程」（北京商报援引专家评价）。

## 商业化策略

2025 年收入约 5 亿元人民币，2026 年预计约 10-12 亿元（《财经》报道口径，公司未官方回应；对比：2025 年智谱营收 7.24 亿元、MiniMax 约 5.43 亿元）。终端 Agent API 调用量截至 2025 年底连续三个季度累计增幅近 170%，开放平台 API 调用量一年增长近 20 倍、活跃开发者增长约 5 倍。资本运作节奏极快：2026-01-26 完成超 50 亿元 B+ 轮（刷新 12 个月内中国大模型单笔融资纪录）；2026-05 Pre-IPO 轮融资近 25 亿美元（约 170 亿元，港投公司「香港淡马锡」首次背书），估值 40-120 亿美元（不同媒体口径：《财经》40-60 亿美元，腾讯新闻区间上限 120 亿）。2026-04-02 完成股份制改造，拟成为继智谱、MiniMax 之后港股「大模型第三股」，计划募资约 5 亿美元。

## 生态壁垒

产业链资本深度绑定是最大特色：Pre-IPO 轮引入华勤、龙旗（全球手机代工第一梯队）、豪威（图像传感器）、中兴等消费电子产业链公司，覆盖整机制造到上游核心器件（腾讯新闻 2026-05-08）。早期股东含红杉中国、启明创投、IDG、五源、顺为、联想创投、腾讯、上海国投等。治理层绑定「AI+车」：旷视科技联合创始人印奇 2026-01 出任董事长，同时任千里科技（吉利系）董事长，形成「模型-手机-汽车」闭环叙事（媒体称「中国版 xAI+特斯拉」故事）。壁垒逻辑：终端嵌入切换成本高、收入可预测性强于 C 端流量；风险在于云端开发者生态弱（OpenRouter 排名下滑），故事高度依赖手机/汽车出货周期。
