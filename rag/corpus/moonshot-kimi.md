# 月之暗面（Kimi）

> 数据来源：今日头条（2026-07-22）、腾讯新闻（2026-07-27）关于赴港上市与融资历程的报道、国信证券《人工智能行业专题(16)》（2026-04，东方财富研报中心 PDF）。检索日期：2026-07-27，研报层补充于 2026-07-28。

## 券商研报观点

国信证券行业深度（2026-04）对月之暗面的画像：团队约 300 人，组织文化「共识驱动——少数精英的共识能引领方向」；核心优势为长上下文能力与智能体（Agent）集群协同，正迈向原生多模态。K2.5 代模型总参数 1 万亿、激活 328.6 亿、上下文 262K，API 定价 $0.6（入）/$3（出）每百万 Token。国信口径 2026-02 ARR 为 1 亿美元——与后续媒体报道的「2026-06 站稳 3 亿美元」形成连续增长链条，卖方数据与媒体数据相互印证（国信证券 2026-04-19 研报）。

## 技术路线

旗舰模型 Kimi K3（2026-07-16/17 发布）：总参数 2.8 万亿，全球首个开源 3 万亿级别模型；MoE 稀疏架构，896 个专家每次推理仅激活 16 个；自研 KDA 混合线性注意力机制，扩展效率较上一代提升约 2.5 倍；100 万 Token 上下文窗口。Frontend Code Arena 前端代码评测 1679 分登顶全球第一，超越 Claude Fable 5 与 GPT-5.6 Sol——开源模型首次在权威编程榜单超越全部海外闭源模型（腾讯新闻 2026-07-27）。K3 发布 72 小时内美股 AI 板块市值蒸发约 4700 亿美元，黄仁勋公开表态美国公司「绝对应该」被允许使用中国模型。

## 产品定位

C 端以 Kimi 智能助手起家（长文本处理心智），2026 年重心转向「开源模型 + API 平台」双轮：API 收入占比已超七成，产品覆盖 200 多个国家和地区。企业客户数量截至 2026-06 突破 12 万家（腾讯新闻 2026-07-27）。K3 发布后因算力紧缺主动暂停 C 端新用户订阅——国内罕见的因需求过载限流案例。

## 商业化策略

ARR 三级跳：2026-03 突破 1 亿美元 → 2026-05 达 2 亿美元 → 2026-06 中旬站稳 3 亿美元，三个月翻三倍；海外付费用户同期增长 400%（今日头条 2026-07-22）。融资历程：2023-06 天使轮 2 亿+美元（估值 3 亿）→ 2024-02 A+轮 10 亿+（25 亿）→ 2024-08 B 轮 3 亿+（33 亿）→ 2025-12 C 轮 5 亿（43 亿）→ 2026 年 1-2 月连续三轮（5 亿/7 亿/7 亿美元，估值 100 亿→180 亿）→ 2026-05 美团龙珠领投 D 轮约 20 亿美元（估值 200 亿）→ 2026-06 底新一轮投前 315 亿美元。累计融资超 376 亿元人民币，为国内大模型创业公司融资最多（华峰资本统计）。2026-07 计划 8 月启动 Pre-IPO 轮，目标投前估值 500 亿美元，与高盛、中金洽谈保荐，拆除 VIE 架构，最快 6 个月内登陆港股。

## 生态壁垒

创始人杨植麟（清华系）持股 51.83%，为控股股东——国内大模型公司中创始人控制权最强的之一。壁垒：开源社区心智（K3 全球第一的编程榜单）+ 12 万企业客户 + 200 多国海外覆盖。投资方含美团龙珠、阿里等。风险：估值半年涨超 7 倍（43 亿→315 亿美元）存在泡沫争议；算力紧缺已实际制约 C 端增长；与 DeepSeek（估值 450-490 亿美元）正面竞争开源生态位。
