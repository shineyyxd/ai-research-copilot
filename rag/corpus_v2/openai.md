## 技术路线

闭源路线，旗舰 GPT-5.4 / GPT-5 Pro 系列，多模态能力覆盖最广（文本/图像/语音/视频），旗舰上下文窗口 400K tokens。MMLU 91.4% 领先（valueaddvc.com 2026 对比），但编程基准 SWE-bench Verified 65-67% 落后于 Claude（72.7%）。Codex agent + GPT Store 构建开发者生态。算力：多云多芯片布局，但媒体评价供应链绑定深度与储备规模已被 Anthropic 赶超（证券时报 2026-05-29）。

## 产品定位

全球最大消费级 AI 入口：ChatGPT 周活超 9 亿、付费订阅超 5000 万（2026 年中口径）。收入结构约 70% 来自消费端、30% 来自 API 与企业合同——与 Anthropic 正好相反。美国聊天机器人市场份额约 45-53%（不同口径），仍居第一，但一年内从 69.1% 滑落至 45.3%（fast.io 2026），被 Gemini 与 Grok 蚕食。

## 商业化策略

2026-03 完成 1220 亿美元融资、估值 8520 亿美元（英伟达、亚马逊、软银领衔，微软持续参与）；月收入 20 亿美元、年化约 240-250 亿美元；2026 全年营收目标 300 亿美元。已秘密递交 IPO 文件，目标 2026-09 上市、估值 7300-8500 亿美元区间（若破万亿则重夺估值第一）。仍在巨额亏损：2026 年预计亏损 140 亿美元，盈利预期要到 2029 年后（腾讯新闻 2026-05-30）。2025 年现金消耗超 70 亿美元。非营利转营利架构转换预计 2026 年内完成。

## 生态壁垒

最大消费者品牌心智 + 最深开发者生态（工具链、插件市场、人才池）+ 微软 Azure 分发。企业收入占比已超 40% 且年底有望与消费端持平。风险：估值与营收被 Anthropic 反超（2026-04 起），企业 AI 支出份额从主导地位滑落；消费订阅模式受留存/ARPU/免费转化制约；监管与架构转换的法律审查仍在进行。
